- The g02 author overwrote existing test `tests/ch7/test_illegal_iterator_argument_without_with.sv` using the test-writing script.
  - The author has reverted it to `git show HEAD:`. Verified no tracked-file changes before integration.

  - 6.24.3 includes the class in the bitstream type, giving examples of forms like `longint'(this)`.
