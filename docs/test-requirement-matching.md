全 6799 本を対象に、引用節から照合候補を列挙しました。
刺激・期待結果に基づく要求対応が登録済みのテストは 4408 本、未登録は 2391 本です。

**全テストの意味上の照合は未完了です。** 候補列挙は自動処理で、対応の承認ではありません。
登録済み本数も、少なくとも一つの要求との対応がある本数で、各テスト全体の確認完了数ではありません。
一つのテストの複数観測や、同じ要求を検証する別テストの対応も順次記録します。

## 台帳の読み方

- `registered_requirement_ids`: 刺激・期待結果を確認して対応を登録した要求。証拠とレビュー担当・日付は `behaviors.json` の `checks` にあります。
- `collective_requirement_ids`: 複数テストで分担する要求への参加。そのテスト単独では要求全体を検証したことにならず、指定グループの全成功が必要です。
- `unapproved_candidate_ids`: 引用節と正常／違法の区分が一致する候補。名前や引用だけから対応済みにしていません。
- `interpretation_pending_ids`: 引用節の解釈保留項目。対応の承認対象から分けています。
- `different_case_kind_ids`: 引用節は一致するが正常／違法の区分が異なる項目。要求行が複数条件を含む場合は、要求の分割が必要かも確認します。
- `broader_citations`: 引用節の下位節にも要求がある箇所。直接候補がなくても、テストが無関係という判定にはなりません。
- `inputs_sha256`: 照合候補を作成した入力の識別子。テスト・期待値・補助ファイルが変われば再照合します。

候補のない要求や未登録のテストを、テストが存在しない証拠として扱わないでください。
複合要求の一部しか観測しないテスト、必須の境界条件を欠くテスト、誤った期待値や違法な刺激を含むテストは、そのまま要求全体に対応付けません。

## 対応を保留した理由

1032 本について、確認した範囲と判断を [レビュー判断台帳](../coverage/test-matching-reviews.json)に記録しました。
これは範囲を限定した判断の記録で、テスト全体のレビュー完了数ではありません。対応登録や動作網羅率を増やす情報としては使用しません。
入力ハッシュ・根拠の文字列・要求IDを検査し、変更後の判断の使い回しを防ぎます。

- `citation_refinement`: 72 件。
- `compound_requirement`: 128 件。
- `oracle_issue`: 106 件。
- `partial_observation`: 1473 件。
