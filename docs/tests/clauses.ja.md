# テストが引用する条項

[English](clauses.md) / [日本語](clauses.ja.md)

引用条項は探す手掛かりです。節の全動作を証明するものではないため、[引用本数から判断できる範囲](../faq.md#q17-do-two-tests-per-clause-cover-every-behavior)を確認してください。

[すべての章](README.ja.md) .このページは、IEEE 1800-2023の3章から40章までについて、下位の条項を持たない条項（`tools/clauses.txt`にある番号）を、テストが`:lrm:`で引用しているかどうかで数えます。条項は親条項を通してだけ引用されることもあります。その場合、何を確かめているかは引用からは分かりにくくなります。それ自体の動作を定めない条項、第34章、ツールやその設定に任された動作、VCDファイルの内容は対象外です（`tools/clauses.txt`の印）。このページは`tools/suite_catalog.py`が書きます。
