# 規格テストの補強（2026-10-22）

## 範囲と到達点

開始時点は`51173db`、テスト総数3,801件。
既存の集計対象であるIEEE 1800-2023の本文3〜40章の末端932節について、
直接引用するテストはすでに全節に存在したが、187節は1件だけだった。

今回、**111テスト（正常系99件・負例12件）とC補助ソース6件を追加**した。
1件だけだった187節すべてに別ケースが入り、次の状態になった。

- テスト総数: **3,801 → 3,912**。
- 対象節に直接引用するテストがある割合: **932/932（100%）**。
- 対象節に直接引用するテストが2件以上ある割合: **745/932 → 932/932（100%）**。
- 1件だけの節: **187 → 0**。
- 1件だけでオラクルが規格のみの節: **65 → 0**。
- 規格のみを根拠とするテストしかない節: **259 → 239**。

これは**節単位の直接引用とテスト数の指標**である。規格中のすべての要求、
例外、境界、実行順序、機能の組合せを列挙した動作網羅率は未計測。
既存の対象外227節、34章のprotected envelopes、附属書全体についての
動作網羅を、この100%に含めてはいない。分母や除外規則は変更していない。

## 追加した検証

既存テストの名前や入力値だけを変えて件数を増やす方法は採らず、
各テストのコメントに規格の節と観測する動作を記した。例えば以下を追加した。

- コピーと共有の区別: 配列引数、連想配列代入、クラスとstruct、
  queue要素参照の保持、eventの再束縛。
- 型と値の境界: 降順enum名とprevの循環、失敗するenum cast、
  符号付き連想キー、未知キーでの書込み、幅の狭い走査引数。
- 実行時点: 遅延付きblocking代入の宛先選択、引数copy-out、
  Preponed/Observed/Reactive/Re-NBA、PLI callback後のHDL再評価。
- 独立した負例: 各版の予約語、非互換cast、realを含む連想キー、
  interface classの構築、checker covergroupのconstant actual。
- 階層と接続: non-ANSI外部port名と内部連結、wildcard接続の上書き、
  安定したdefparam、特定instanceへのbind、modportのsliceとvirtual参照。
- I/Oの実データ: バイナリ短読込みとEOF、pushback後のseek、flushとerror文字列、
  packed struct/enumのメモリ出力とaddress tokenの有無。
- VCD: ファイルを読み戻し、型・幅・値・時刻・off/on/checkpointを確認。
  識別子コードと時刻単位はヘッダーから取得し、処理系依存の具体値を固定していない。
- VPI: statementの種類に加え、condition/body/else、loop初期化・増分、
  disable先、repeat control、nettype aliasのリンク、数値attributeを確認。
- その他: chargeの保持・減衰・再充電、非抵抗switchの強度、UDPのpreset、
  SDFのlabel式とpulse境界、同期PLAと非同期PLAの差。

追加テストの具体的な説明・節番号・オラクルは
[カタログ](tests/README.md)、現在の全体集計は
[coverage-depth.md](coverage-depth.md)を参照。

## 期待値と検証

期待値は、提供されたIEEE Std 1800-2023本文と抽出テキストに照らして決めた。
実行結果が違う場合に、その結果へ期待値を合わせる変更は行っていない。
例えば短いfreadでは規格から確定するbyte数と上位byteを検査し、
未読部分のbit値は期待値で拘束しない。

新規111件のオラクルは、両リリース37件、Icarusのみ16件、
5.052のみ31件、規格のみ27件。
新規ケースはIcarus 13.0と5.052で照合し、4値のケースは2値処理系を
オラクルにしていない。規格のみのケースは独立した実行確認が未完了であり、
特に高度なchecker、VPI、nettype、SDF等が含まれる。
確認できた差異は[simulator-differences.md](simulator-differences.md)に記載した。

実施した確認:

- 新規111件をIcarusランナーへ渡し、オラクル対象 **53/53一致**。
  対象外58件は既知差分として区別。
- 新規の5.052オラクル対象 **68/68一致**。
- 新規111件をpyslang 12.0.0の2023モードで構文・意味・手続き解析。
  負例12件の拒否を確認。正常系に出た診断は、interconnectのprimitive接続、
  resolved nettypeの別名、幅の狭い連想配列走査引数の3ケースで、
  本文に明記された許容規則と照合し、期待値を変更していない。
- C全214ファイルの構文チェックはエラー0。既存の未使用変数警告1件。
- suite_stats、生成器、suite_catalog、coverage_depthの整合性チェックは成功。
- メタデータ検査は **3,912件、新規問題0、既知378、解消0**。
- 深度チェックは下限2で成功、下限3では不足437節を示して失敗。
  親節引用・未引用・除外節の小さな入力でも、直接引用だけを数えることを確認。

今回は追加ケースを実行対象にしており、既存テスト全体のシミュレーションを
再実行した結果ではない。既存テストのソースと期待値は変更していない。

## 再発を防ぐチェック

`tools/coverage_depth.py --check --minimum-tests 2`をCIに追加した。
子節の代わりに親節を引用しても通らず、未引用の節も分母に残る。
テストが減って1件だけの対象節が生じた場合も、資料の再生成だけではCIを通せない。
これは件数の下限を維持する仕組みであり、テスト内容の妥当性のレビューも必要。

VCDを既存ランナーで検証するため、Icarusランナーはファイルを開いたという
`VCD info: dumpfile ... opened for output.`の診断行だけを追加で除去する。
HDLが出す検証結果の行は比較対象に残す。
