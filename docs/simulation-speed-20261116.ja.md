# kirimasim 0.1.0 と Icarus 14.0 devel：Mac・WSL2 の比較と対策

[English](simulation-speed-20261116.md) / [日本語](simulation-speed-20261116.ja.md)

同じ13本での時間比の幾何平均は **Mac 1.065、WSL2初回1.193、WSL2再測定1.220**（kirimasim/Icarus）でした。**WSL2の正式版測定は2回とも途中で別ctest/UVMが重なった参考値**です。別に行ったLinux試作では広幅約51%、ゲート約16%、メモリ約14%の時間短縮を確認し、全13本の出力・カウンタも照合しました。[追加の受領結果](simulation-speed-wsl2-followup-20261116.ja.md)を含め、P1の閾値を新設せず内訳と対策を示します。

## 読み方と測定条件

- [Macの詳細と全サンプル](simulation-speed-mac-20261116.ja.md)：Apple M5 Max、18論理CPU、128 GiB、macOS 27.2.1、AppleClang 21.0.0。OSの索引作成・エディタの背景活動は記録済みです。
- [WSL2の詳細と受領検証](simulation-speed-wsl2-20261116.ja.md)：Ryzen 9 7950X、32論理CPU、110 GiB、Ubuntu 24.04.4 / WSL2、Clang 20.1.8。別ジョブの影響とばらつきを明記しています。
- [原因調査・試作パッチ・効果測定](simulation-speed-analysis-20261116.ja.md)：Macのprofilingと、正式版／試作／Icarusの同時計測を記録しています。

kirimasimは v0.1.0 `cfa2ccd75989c1ebb9ed63303271183377364cf0`、Icarusは作業開始時に取得した14.0 devel `1eba3690d8314d79927df8690a7d97642dd93ce0` に固定しました。既存12本と規格由来のX/Zベンチ1本、N、期待値、driver、adapterのhashは両環境で一致しています。正式版の3測定、計858実行の出力と終了状態を検査しました。

各toolでn=1のwarmup1回、n=1とNを各5回、直列・順序交替で実行しました。主指標Δは `median(T(N))−median(T(1))`、比は `Δkirimasim/ΔIcarus` です。1未満ならkirimasimの時間が短い値です。Icarusのコンパイルは別記、kirimasimの解析とelaborationは実行時間に含まれます。全実行時間・n=1・min/max/MADも各詳細に残しています。

CPU、OS、compilerの異なる環境内の比を並べています。両マシンの絶対速度をひとつの指標へ混ぜず、幾何平均も各ベンチ等重みの記述統計として扱います。起動時間の完全分離や、差の統計的有意性は主張しません。

## 原因と対策の優先順位

広幅のbit単位処理と、VMが繰り返す不変な型の取得が、先行して改善する候補です。同じ2パッチの効果は両環境で測定できました。MacでのCPU内訳と[原因調査](simulation-speed-analysis-20261116.ja.md)、[Linuxの追加測定](simulation-speed-wsl2-followup-20261116.ja.md)に分けて記録しています。

| ベンチ | Mac 時間削減 | WSL2 時間削減 | WSL2 試作/Icarus |
|---|---:|---:|---:|
| `wide_arith` | 73.87% | 51.36% | 1.223 |
| `gate_udp` | 18.93% | 15.72% | 1.478 |
| `mem_rw` | 14.67% | 14.16% | 1.487 |
| `nba_shift` | 17.09% | 18.57% | 1.102 |
| `proc_wait` | 7.75% | 14.01% | 1.270 |

Linuxの試作もまだこの5ケースではIcarusより長く、残るVM dispatch・静的trigger構築・一時bufferの負荷が次の調査対象です。両環境の5ケースを各5回測定し、全13本の期待出力を検証しました。WSL2では全13本の全カウンタが正式版とMac試作に一致し、Wide 7/7・Valsem 15/15・追加122,184回の参照照合も合格と報告されています。正式採用前には全体local CI、sanitizer、型/境界/aliasの正式回帰、大規模SIRのメモリ/起動の確認が残ります。本体mainへは未適用です。
