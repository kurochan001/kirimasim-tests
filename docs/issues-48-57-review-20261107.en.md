# Issues #48 to #57: decisions and test fixes (2026-11-07)

[English](issues-48-57-review-20261107.en.md) / [日本語](issues-48-57-review-20261107.md)

We compared the text of IEEE 1800-2023 with the current tests, their expected outputs and local runs. The base is `kirimasim-tests` at `d9b55bfb`. The standard's text is not reproduced. This is an AI review by Claude Opus 5.5, not an independent human approval.

Five of the ten issues are mistakes in the tests and were fixed. The other five change no test.

## Corrected tests

| Issue | Test | Mistake and fix | Expected output |

| [#48](https://github.com/kurochan001/kirimasim-tests/issues/48) | `ch16/test_ch16_sim_checker_history` | 16.6 allows no side effect in a function in an assertion's expression, but the function wrote a checker variable. The function is gone, and `$future_gclk(v)` is now the property itself. The action block runs at the next global clock tick, so the pass action requires `v` to be 1 and the fail action requires it to be 0. | Unchanged |

## Left unchanged

| Issue | Reason |
| --- | --- |
| [#49](https://github.com/kurochan001/kirimasim-tests/issues/49) `ch19/test_cg_four_state_literal_wildcard_enum` | 19.5.4 and 19.5.7 disagree, and the test's comment already says that it follows 19.5.4. This is the [decision on #28](issues-24-27-28-review-20261107.en.md#left-unchanged). |
| [#51](https://github.com/kurochan001/kirimasim-tests/issues/51) four `ch18` tests and `ch21/test_illegal_value_plusargs_bad_format` | The rule that an error line must carry `file:line:` stays, as [decided for #27](issues-24-27-28-review-20261107.en.md#left-unchanged). That form is how a test tells whether the design was rejected at the right place. The `ch18` diagnostics have neither a file name nor a line number, so relaxing the tests would lose that check. |
| [#53](https://github.com/kurochan001/kirimasim-tests/issues/53) `ch29/test_illegal_udp_table_without_endtable` | A report on line 24 can have any wording. Line 23 is a legal table row, so a report there has to ask for `endtable`. This was decided in the [correction of 2026-10-27](nightly-suite-corrections-20261027.en.md), and `tools/test_nightly_diagnostics.py` keeps it, so that an unrelated error does not pass. Relaxing the test as proposed made that regression test fail. |
| [#54](https://github.com/kurochan001/kirimasim-tests/issues/54) `ch17/test_illegal_checker_variable_initial_assignment` | The same rule applies. The proposed fix was tried locally and did not pass: the location is on a different line from the error, and `judge_illegal` needs both on one line. |
| [#55](https://github.com/kurochan001/kirimasim-tests/issues/55) `tools/run_kirimasim.py` | This runner is only for kirimasim, which rejects an illegal design with exit code 2. Any other code fails so that an abnormal end does not count as a rejection. A simulator with other exit codes needs its own runner, `tools/run_<simulator>.py`. |
