# メタモルフィック検査

[English](metamorphic.en.md) / [日本語](metamorphic.md)

意味を変えない変換をテストに施し、変換の前後を同じシミュレータで実行して、正規化した出力を比べます。期待出力を使わないので、期待値の誤りに左右されずに、シミュレータの不具合やテストの隠れた依存を探せます。ツールは`tools/metamorphic.py`で、リポジトリの`.sv`と期待値は書き換えず、一時フォルダの写しを変換します。ランナーのコードも変えず、その判定の関数を呼び出し、比べる直前の正規化した出力を受け取ります。

<a id="transforms"></a>

## 変換と、意味を変えない根拠

- M1 識別子の付け替え：ファイルが宣言する変数とネットの名前を一律に置き換えます（5.6、3.13、23.9：名前は宣言と使用を結ぶだけ）。名前が期待出力・文字列・VCDやSDFのファイルに現れるテスト、Cコード、`:top_module:`、複数のファイル、`include`、`define`、エスケープした識別子を使うテストは除きます。
- M2 空白とコメント：文字列・コメント・指令の行の外で、セミコロンの後にコメントと改行を足します（5.3、5.4：空白とコメントはトークンを区切るだけ）。行やファイルの位置を表示しうるテスト（`__LINE__`、`line、%l、重大度のタスク、アサーション）と、実行がファイルの位置を表示したテストを除きます。
- M3 時間の単位の拡大：すべての`timescale指令の単位と精度を10倍にします（3.14、22.7：遅延は単位で数え、$time・$stime・$realtimeは単位で返す、20.3）。単位付きの時間リテラル（5.8）、%tと$timeformat（21.2.1.3、20.4.2）、$printtimescale、$timeunit、$timeprecision、timeunit宣言、SDF、値の変化のダンプを使うテストと、`timescale指令のないテストを除きます。

どの変換でも、実行がパスを表示したテストは除きます。シミュレータが診断を標準出力に書くことがあるためです。出力が違ったときは元のテストをさらに3回実行し、元の出力が変わるなら「元の出力が実行ごとに変わる」として記録します。

<a id="findings"></a>

## 分かったこと

- Icarus Verilog 13.0では、どの変換でも、変換の前後で出力が違ったテストはありませんでした。
- M2で比べた3本（`gen/ch20/test_gen_cross_query_*`）は、元のテストを同じように実行し直しても出力が変わりました（同じ日の別の実行では8本。実行のたびに変わります）。連結や複製の引数（幅が32の倍数でないもの）に対する`$countones`の非決定性で、[シミュレータの差異](simulator-differences.ja.md)の20.9の行と`generators/interaction_query.py`の`icarus_unstable`に記録済みの種類です。2026-11-12にはmacOSで変動しませんでしたが、今回はmacOS arm64で、例えば`test_gen_cross_query_w129_l_prefix_x_low_zero`を12回実行して`ones=`が2（9回）、8（2回）、9（1回）と変わりました（規格の値は2）。変換の影響ではないので、シミュレータの不具合に分類しました。
- 最初の試行では76件が違って見えました。Icarusが診断を標準出力に書き、そこにファイルのパスと行番号が入ること、VCDやSDFのファイルを通して名前が観測されることが原因で、変換の除外漏れでした。パスの置き換え、実行の後の除外、M1の除外（文字列・VCD・SDF）を足した後は、0件です。
- kirimasimでは、どの変換でも不一致はありませんでした。
- テストの隠れた依存は見つかりませんでした。
