## 結果と判断

3つの試行トレースは、独立したフォーマル試行モデルのすべてのサンプリング入力tickと一致する。`goto_nc.sv`（21 tick）、`next_ev.sv`（24 tick）、`binary_ops.sv`（25 tick）である。これらのモデルは外部作業材料である。それらの刺激関数を`m0.audit_stimulus`へ転記する。モデル出力のアサーションは評価器への入力ではない。トレースのフィクスチャは、選択したすべてのエッジに加え、最後のタイムスタンプも保持する。

条項に基づく小規模な試行用評価器は、それぞれ3、10、25件のアクションイベントを生成する。3つのテストすべてで、選択肢A（Pythonアダプタ）と選択肢B（Icarusのアクション再生）は、同一の出力を生成する。両実装が完成してから、その出力を既存の`.expected`ファイルと比較しました。3つすべてが一致する。テスト、期待値、メタデータは変更していません。

v1 に対してオプション A を使用します。`#0` の後にモジュール手続きの動作を置くオプションB実験を行った。これはInactive領域であり、1800-2023 4.4.2.3～4.4.2.6、16.14.1、16.14.3が要求するReactive領域ではない。再現可能なNBAプローブは、予約されたアクションと同じタイムスタンプで`current <= 1`を設定する。再生時には0を読むが、Reactive領域のアクションでは1を読まなければならない。時間精度の1単位だけ移動しても`$time`が変わるため、それも一般的な解決策にはなりません。選択肢Bは実験的なものであり、決して参照バックエンドではない。

## M1: 解析と意味論

M1エンジンは、3つの固定M0評価器とは別である。

- `parser.py`は、表16-1と表16-3の結合強度と結合方向を実装する。v1のシーケンス／プロパティ演算子、クロック／disableプレフィックス、`if`／`else`、`case`、および整数型の真偽式を解析する。
- `module.py`は名前付けされた宣言と指令を位置付ける。位置指定、名前指定、省略、および既定の式引数を束縛し、仮引数の型を継承し、16.8.1／F.4.1のキャストを挿入し、モジュール本体の定数パラメータを解決する。また、空の既定クロッキングブロックと既定の無効化条件をサポートする。再帰定義と複数クロックは明示的に失敗する。
- `values.py`は、有限幅の4状態整数型の式を評価する。算術の文脈によるサイズ決定、符号、選択、論理／ビット単位演算子、等価比較、および三項演算子のマージを含む（6.11、6.24.1、11.4、11.6、11.8）。
- `automata.py`は、重み付き正規微分を使い、1tickずつシーケンスを消費する。係数は多重性を保持する。融合は空のオペランドを除外する（16.9.2.1）。`first_match`は、同順位を含む最初のマッチを固定する（16.9.8）。将来の成立可能性には、抽象的なtop文字と残余のサイクル検出F.5を使い、有限の先読み上限は設けない。
- `engine.py`は、シーケンスのマッチ、評価試行ごとのプロパティ判定、およびシーケンスカバレッジを公開する。含意は、前件のすべてのマッチを検査する。followed-byは、F.3.4.3.6の双対形式を使用する。プロパティの判定には、そのtick／時刻を含める。シミュレータは アサーション表現を評価しません

既にサンプルされた値を使った例:

```python
from sva_reference.engine import Engine

engine = Engine([{"a": "1", "b": "0"}, {"a": "0", "b": "1"}], times=[5, 15])
result = engine.property("a |=> b")
assert (result.status, result.tick, result.time) == ("success", 1, 15)
```

Python API のティックインデックスはゼロベースである。`Match(start, start - 1)`は空区間を表す。シーケンスは、重複する`Match`オブジェクトを返すことがある。重複を取り除かないでくださいプロパティカバーは，一度の試みに対して多くとも1回の成功を報告する。

`Engine` 入力は既にサンプリングされており，最初のクロックエッジがタイムゼロの場合は，宣言デフォルトを含む。文字列は、符号なしのbitベクトルである。符号付き宣言には`Bits(bits, signed=True)`を使用する。ゼロ以外を基点とする、または昇順のpacked範囲には、`Bits(bits, lsb=..., ascending=...)`を使用する。VCD 値から宣言されたタイプを推測しない。`parse_module` は拡張スペックとソースアクションを返します。刺激やアクションブロックを実行しません

有限単語は16.12.21 / F.5.3.2の 4つの満足度レベルを持っています`status="holds"`または`status="pending"`の結果には、判定tickがない。`finite_truth`は中立的な有限語満足度を記録します特に、weakの未完了シーケンスは成立し得る一方、strongの未完了シーケンスは保留中となる。どちらの結果にも、仮の最終クロックtickで成功／失敗アクションを割り当てない。前件の不成立や、条件分岐で選択されなかったことによるvacuityを記録する。F.5.3.3の一般的なnonvacuityの関係は、依頼されたv1の対象外のままである。

`disable iff`には、順序の付いた完全な現在値イベント列が必要であり、サンプル値やスロット末尾のVCD値では代用できない。各Observed tickには`Current(time, values)`を、その他の更新には`Current(time, values, "change")`を指定する。同じタイムスタンプのイベントは領域順序を保持する。評価試行を取り消せるのは、開始時のObservedスナップショットから判定時のObservedスナップショットまでのイベントだけである。オフクロックリセットで 待ち受ける試みもキャンセルできる現在値の証跡がなければエラーとなる。M0 VCDのフィクスチャは、意図的にそれを提供するとは主張しない。

### 刺激の射影とキャッシュの証跡

`bridge.py`は、トップレベルの基本整数型宣言の幅、符号属性、2状態かどうか、packed範囲を`Bits`へ渡し、VCDと照合します。欠落したタイプメタデータや間違ったクロック／エッジを拒否する。検査用の人工的なテストは、符号付きの昇順ベクトル、ゼロ以外の添字基点、2状態での未知値、および幅を確認する。
